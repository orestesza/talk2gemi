# talk2gemi 1.0 Beta Release & Fix Notes (2026-10-18)

> 🇨🇳 [中文版发布说明 (Chinese Release Notes)](2026-10-18-v1.0-beta-release.md)

Date: 2026-10-18. This release delivers a permanent fix for long-speech audio truncation, standard macOS companion packaging (snowy owl menu bar icon, drag-and-drop DMG installer), and multi-device backup tooling, designated as **talk2gemi 1.0 Beta**.

## I. Core Features & Major Improvements

### 1. Complete Fix for Speech Truncation on Replies Over 30 Seconds
- **Decoupled WebSocket Reception & Hardware Playback Backpressure**:
  In `relay_server.py`, introduced `self.playback_queue` and an asynchronous `_playback_worker`. When `_gemini_receive_loop` receives cloud audio packets, incremental captions, and `turn_complete` events, it pushes them into the in-memory queue immediately. This drains the WebSocket buffer within milliseconds, eliminating WebSocket 1006 abnormal disconnects caused by BLE 3-frame hardware playback backpressure.
- **Keepalive Loop Protection**:
  In `_gemini_keepalive_loop`, restricted reconnection attempts with `if not self.busy:`. While a playback turn is active or audio remains queued, the keepalive loop will not preemptively cancel the active `receive_task`.
- **Physical Long-Recitation Acceptance**:
  Requested a complete recitation of Bai Juyi's poem *The Charcoal Seller* on hardware (`turn_id = 153018e6-12c5-430c-ab22-29ee4fae6f47`). Audio played smoothly and continuously for **36.5 seconds** (47 downlink audio chunks, 1,168,320 PCM bytes) until the final line, with status properly recorded as `completed`.

### 2. macOS Companion Packaging & Snowy Owl Menu Bar Icon
- **Black Snowy Owl Menu Bar Icon**:
  Replaced plain text "T2G" with a black snowy owl template image (`owl_status.png` 18x18, `@2x.png` 36x36), `isTemplate = true`, automatically adapting to macOS Light and Dark appearance.
- **Standard macOS DMG Installer**:
  Built `dist/Talk2Gemi.dmg` (94MB UDZO image with an `/Applications` symlink and custom Talk2Gemi volume icon for terminal-free drag-and-drop installation) and a portable zip package `dist/talk2gemi-mac-arm64.zip` (50MB).
- **Zero-Secret Security Audit**:
  Audited installer packages and bundled environments to verify that 0 API keys or private credentials are leaked. Keys are entered exclusively by the user and stored in the macOS Keychain.

### 3. Multi-Card Backup & Device Tooling
- Developed `scripts/backup_card.py` to auto-detect card serial ports, verify USB identity, read ROM MAC, dump the 8MB physical flash, and parse partition tables.
- Successfully archived the factory firmware for a second card (`muse` factory firmware, MAC `4C:11:AE:32:35:E4`) into `backup/muse/` with an automated restoration script (`backup/muse/restore_muse.sh`).

### 4. Automated Test Suite
- Host Python test suite expanded to **43 tests**, covering direct text queries, speech interruption, long speech playback queue draining, state transitions, and Keychain authentication. All 43 tests pass cleanly.
