# talk2gemi 1.0 Beta 发布与修复记录（2026-10-18）

> 🌐 [English Release Notes](2026-10-18-v1.0-beta-release.en.md)

日期：2026-10-18。本项目完成长语音断流彻底修复、macOS 伴侣应用标准工程化打包（雪鸮菜单栏图标、标准 DMG 安装包）以及多设备支持，正式发布 **talk2gemi 1.0 Beta**。

## 一、 核心功能与重大改进

### 1. 长语音回复（>30 秒）尾段截断与超时彻底修复
- **解耦 WebSocket 接收与硬件播放背压**：
  在 `relay_server.py` 中引入 `self.playback_queue` 与异步 `_playback_worker`。`_gemini_receive_loop` 在收到云端音频流、增量字幕与 `turn_complete` 事件后立即推入播放队列，毫秒级排空 WebSocket 缓冲区，不再因 BLE 3 帧硬件播放背压而发生 WS 1006 超时关闭。
- **保活巡检与播音保护**：
  在 `_gemini_keepalive_loop` 中严格限定 `if not self.busy:`，当单轮播报正在进行或队列尚有积压音频待排空时，严禁抢占取消 `receive_task`。
- **实机全诗背诵验收**：
  在设备端要求全文背诵白居易《卖炭翁》（`turn_id = 153018e6-12c5-430c-ab22-29ee4fae6f47`），连续完整播报 **36.5 秒**（47 个下行音频块，共 1,168,320 字节 PCM），末尾“半匹红绡一丈绫，系向牛头充炭直”清晰完整播毕，状态完备落库为 `completed`。

### 2. macOS 伴侣应用标准工程化与雪鸮菜单栏图标
- **黑色雪鸮菜单栏图标**：
  将菜单栏状态图标从原纯文本“T2G”替换为黑色雪鸮模板图标（`owl_status.png` 18x18, `owl_status@2x.png` 36x36），`isTemplate = true`，自动完美适配 macOS 浅色/深色外观。
- **标准 macOS DMG 安装包**：
  构建 `dist/Talk2Gemi.dmg`（94MB，UDZO 高压缩格式，集成 `/Applications` 替身链接、自定义 Talk2Gemi 磁盘卷标图标，支持免命令行一拖即装）以及独立便携免安装 ZIP 包（`talk2gemi-mac-arm64.zip`，50MB）。
- **零密钥安全审计**：
  严格排查安装包与随附环境，确保 0 API Key、0 私人配置外泄，仅在用户初次打开时通过系统钥匙串安全输入和持久化。

### 3. 多卡片固件备份与设备适配体系
- 编写标准全量固件备份工具 `scripts/backup_card.py`，支持自动检测设备串口、USB 身份、读取 ROM MAC、拉取 8MB 镜像、解析分区表并逐分区校验提取。
- 成功完成第 2 台新卡片（`muse` 原厂固件，MAC `4C:11:AE:32:35:E4`）的完整归档与独立一键恢复脚本 (`backup/muse/restore_muse.sh`)。

### 4. 自动化测试套件
- Python 主机测试套件扩充至 **43 项**，覆盖直接文本对话、打断逻辑、长语音播放队列缓冲、音频状态流转、钥匙串鉴权等全部核心路径，运行耗时约 6 秒，全部通过。
